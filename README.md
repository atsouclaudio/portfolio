# 🎨 Mon Portfolio

Bienvenue sur mon portfolio personnel ! C'est un site web moderne et responsive que j'ai créé pour présenter mes compétences, mes projets et permettre aux gens de me contacter.

## 🛠️ Technologies utilisées

- **HTML5** - Structure du site
- **CSS3** - Design moderne avec variables CSS
- **JavaScript** - Animations et formulaire de contact

## 📦 Contenu

- `index.html` - Page principale
- `style.css` - Tous les styles
- `script.js` - Animations et Interactions

## 🚀 Déploiement

Le site est déployé sur Vercel et accessible à l'adresse : [monportfolio.vercel.app](https://monportfolio.vercel.app)
